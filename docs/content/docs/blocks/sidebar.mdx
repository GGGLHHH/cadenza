整页布局，每个都由 [Sidebar](/docs/components/sidebar) 和本库其他组件拼成，
源自 shadcn 的 [Blocks](https://ui.shadcn.com/blocks/sidebar)（MIT）。点 View Code
看整个区块的全部文件：入口 `page.tsx` 在前，`components/` 里的部件随后。

和原版的差别只在三处：组件名跟本库的 Base UI 命名（`DropdownMenuPopup`、
`CollapsiblePanel` 等），图标换成本库的动画图标，以及原例里残留的 Radix 写法
（`data-[state=open]`、`--radix-popper-anchor-width`）换成了 Base UI 的
`data-popup-open`、`--anchor-width`。

每个预览是一个固定高度的框，不是 iframe：侧边栏本来按视口定位，这里用
transform 把框变成它的包含块。所以 ⌘B / Ctrl+B 会同时开合本页所有侧边栏，
窗口窄于 768px 时也按整个窗口切到移动端抽屉。
