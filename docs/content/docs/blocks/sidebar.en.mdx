Full-page layouts, each assembled from the [Sidebar](/docs/components/sidebar)
and the library's other components, ported from shadcn's
[Blocks](https://ui.shadcn.com/blocks/sidebar) (MIT). View Code lists every file
of a block: the `page.tsx` entry first, then the parts under `components/`.

They differ from the originals in three ways only: part names follow this
library's Base UI naming (`DropdownMenuPopup`, `CollapsiblePanel`, …), the
icons are the animated set, and the Radix leftovers in the originals
(`data-[state=open]`, `--radix-popper-anchor-width`) became Base UI's
`data-popup-open` and `--anchor-width`.

Each preview is a fixed-height frame, not an iframe: the sidebar positions
itself against the viewport, and a transform makes the frame its containing
block instead. So ⌘B / Ctrl+B toggles every sidebar on this page at once, and
below a 768px window the sheet takes over based on the whole window.
