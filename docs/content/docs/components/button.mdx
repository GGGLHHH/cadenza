## 用法

```tsx
import { Button, LinkButton } from '@gedatou/cadenza-ui'

<Button variant="outline" size="sm" onPress={() => console.log('pressed')}>
  Save
</Button>

<LinkButton variant="link" href="/docs">
  文档
</LinkButton>
```

`Button` 包 React Aria 的 `Button`，`LinkButton` 包 `Link` —— 两者共用同一套
`buttonVariants`，所以链接按钮不用把 `<a>` 塞进 `<button>` 里。

## Props

除下列样式属性外，其余 props 透传给 [React Aria `Button`](https://react-spectrum.adobe.com/react-aria/Button.html)（`onPress`、`isDisabled`、`isPending` 等）。

| Prop      | 类型                                                                        | 默认值    |
| --------- | --------------------------------------------------------------------------- | --------- |
| `variant` | `default` \| `secondary` \| `outline` \| `ghost` \| `destructive` \| `link`  | `default` |
| `size`    | `xs` \| `sm` \| `default` \| `lg` \| `icon-xs` \| `icon-sm` \| `icon` \| `icon-lg` | `default` |

组件会把选中的 `variant` / `size` 写回 `data-variant` / `data-size`，方便外部按状态选中。

## 定制

分两层。`packages/ui/src/primitives/button.tsx` 是 shadcn 的源码，**不要手改**——它有哈希
校验，改了 `pnpm test` 会失败。要调整外观或 API，改
`packages/ui/src/components/button.tsx`，那是发布边界的接缝。

重新拉取上游版本：

```bash
npx shadcn@latest add -c packages/ui button -o
pnpm test -u   # 接受新哈希
```
