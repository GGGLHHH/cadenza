一个旋转的 `IconLoader`，带 `role="status"`。尺寸默认 `size-4`、颜色继承文字色，
两者都从 `className` 改：

<ComponentPreview name="spinner/basic" />

[Button](/docs/components/button) 的 `pending` 默认组合就是它 ——
那里以 `aria-hidden` 装饰性注入：spinner 只是装饰，状态由按钮自己的
`aria-busy` 说。

## Props

| Prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `aria-label` | `string` | `'Loading'` | `role="status"` 的无障碍名。默认值只进 aria、不上屏（家法的英文兜底），传译文即覆盖 |
| `className` | `string` | — | 类名。底下是纯 svg，不是 Base UI 部件，只收字符串；尺寸用逻辑工具类（`block-6 inline-6`——它们在产物里排在内建 `size-4` 之后，同特异性下覆盖生效）、文字色类改颜色 |
| 其余 | 原生 `svg` 属性 | — | 透传（含 `ref`） |

两种用法的边界：**独立出现**（页面区块加载中）保留 `role="status"` 让它自己播报；
**装饰性出现**（塞进已有自身状态语义的组件里）传 `aria-hidden`，别让两个 live region
抢话。

`SpinnerProps` 类型一并导出。
