offset 分页条：左侧摘要、右侧「每页条数选择器 + 页码指示 + 四个导航按钮」。
组件自己**不产出任何文案** —— 页码指示默认是语言中立的 `3 / 13`，摘要、
「每页」标签、按钮的 aria-label 全部由外部注入，i18n 天然留在业务层。

`page` 和 `limit` 各自支持受控 / 非受控（`useControllableState` 语义：
传 `page` 即受控，传 `defaultPage` 即非受控，两者互不影响）。

## 基础用法

非受控：只给 `total` 和初始值，组件自持状态。摘要是渲染函数，
收到 `{ page, limit, total, totalPages }`：

## 内建守卫

- **`total = 0` 视为「数据未加载完」**，不触发页码钳位 —— react-query
  切换查询时数据会短暂变 `undefined`，此时钳位会把一个过期页码闪进
  URL 同步的调用方。
- **数据已加载且 `page` 越界时自动钳回**最后一页（删光最后一页的行、
  调大 `limit` 后都会发生）。
- **`limit` 为 0 / NaN**（比如从 URL 参数解析而来）时总页数按 1 兜底，
  不会出现 `1 / Infinity` 和 NaN 按钮。

## 键盘交互

控件全部是 React Aria 语义：导航按钮 <kbd>Tab</kbd> 聚焦、<kbd>Enter</kbd> /
<kbd>Space</kbd> 触发，不可用时真实 `disabled`；每页条数是 RAC Select，
<kbd>方向键</kbd> 选择、<kbd>Enter</kbd> 确认、<kbd>Esc</kbd> 关闭。

## Props

| Prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `total` | `number` | — | 总条数；`0` 视为未加载完，不触发钳位 |
| `page` / `defaultPage` / `onPageChange` | `number` | `1` | 页码（受控 / 非受控） |
| `limit` / `defaultLimit` / `onLimitChange` | `number` | `20` | 每页条数（受控 / 非受控） |
| `limitOptions` | `number[]` | `[10, 20, 50, 100]` | 每页条数选项 |
| `showLimitChanger` | `boolean` | `true` | 是否渲染每页条数选择器 |
| `summary` | `(state) => ReactNode` | — | 左侧摘要；不传则该槽位收起 |
| `rowsPerPageLabel` | `ReactNode` | — | 选择器前的可见标签（不传则不渲染） |
| `pageIndicator` | `(state) => ReactNode` | `page / totalPages` | 页码指示 |
| `firstPageLabel` 等 4 个 | `string` | 英文 | 图标按钮的 aria-label，从业务层传译文 |
| `className` | `string` | — | 根元素类名 |

`state` 即导出的 `DataPaginationState`：`{ page, limit, total, totalPages }`。
