## 安装

```bash
pnpm add @gedatou/cadenza-ui react-aria-components
```

在你的入口 CSS 里：

```css
@import "tailwindcss";
@import "@gedatou/cadenza-ui/styles.css";
```

`styles.css` 自带 `@source "./dist"`，Tailwind 会自动扫描到组件用到的类名，无需额外配置。
